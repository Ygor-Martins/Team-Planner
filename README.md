# Team Planner
Projeto para praticar programação utilizando Vue3 e NestJS com a API pokemon


v0.1 - inicio do projeto
1. feito a estrutura do projeto, iniciado os apps NestJS e Vue3 para a instalação dos arquivos base
2. criado os arvidos que serão utilizados no frontend e dado iniciado no teste para leitura inicial e apresentação dos pokemons
3. feito a instalação do module, controller e servic que serão utilizados no backend


v0.2 - gerenciamento do time
1. criada a store do time com Pinia (useTeamStore) com adicionar, remover e limite de 6
2. criado o componente TeamSlot exibindo as 6 posições do time
3. PokemonList passa a exibir só a Pokédex; o time fica no TeamBuilderView
